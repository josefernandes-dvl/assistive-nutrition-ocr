# Protótipo Assistivo com OCR e Análise Nutricional

Projeto de Iniciação Científica: 
**“Desenvolvimento de Protótipo Assistivo com OCR e Análise Nutricional para Apoio a Pessoas com Distúrbios Digestivos”**

## 🎯 Objetivo
Desenvolver um protótipo funcional de aplicativo móvel assistivo capaz de:
- Reconhecer rótulos alimentares via OCR
- Identificar ingredientes e informações nutricionais
- Auxiliar pessoas com distúrbios digestivos na tomada de decisão alimentar

## 🧩 Estrutura do Repositório
- `mobile/` — Aplicativo Flutter
- `backend/` — API REST e integração com OCR e nutrição
- `docs/` — Documentação técnica e acadêmica
- `.github/` — Pipelines de CI/CD

## 🛠 Tecnologias
- Flutter
- Tesseract OCR
- Node.js + Express
- MongoDB
- GitHub Actions
