# Escopo do Protótipo (MVP)

## Funcionalidades no Escopo
- Captura de imagens de rótulos alimentares
- Reconhecimento de texto via OCR
- Identificação básica de ingredientes
- Geração de alertas simples com base em perfil digestivo
- Armazenamento básico dos resultados

## Fora do Escopo
- Treinamento de modelos próprios de Machine Learning
- Reconhecimento perfeito de texto
- Autenticação avançada de usuários
- Publicação em lojas de aplicativos

## Observação
O foco do projeto é a validação técnica e de usabilidade,
não a entrega de um produto comercial.
